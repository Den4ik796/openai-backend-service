# OpenAI Chat Backend

Minimal REST API для ведення чат-сесій з моделлю OpenAI.
Реалізовано розділення інтерфейсів (User UI та Admin Dashboard) для демонстрації розуміння бізнес-процесів.

## Швидкий запуск (Windows)

Для максимальної зручності створено файл `run.bat`.
1. Клікніть двічі на `run.bat`.
2. Скрипт автоматично створить віртуальне середовище, встановить залежності.
3. Прямо в консолі вас попросять ввести ваш `OPENAI_API_KEY`.
4. Сервер запуститься автоматично і сам відкриє ТРИ вкладки у вашому браузері:
   - `http://127.0.0.1:8000/` — Клієнтський чат (UI в стилі ChatGPT).
   - `http://127.0.0.1:8000/admin` — Панель адміністратора (моніторинг токенів та витрат).
   - `http://127.0.0.1:8000/docs` — Документація API (Swagger).

## Архітектура
- Клієнтська частина: Приховано всі технічні метрики, залишено лише зручний UX для спілкування.
- Адмінська частина: Таблиця сесій, яка в реальному часі підтягує дані по витрачених токенах та грошах, а також містить швидкий перехід до Swagger-документації.
