# OpenAI Chat Backend

Minimal REST API для ведення чат-сесій з моделлю OpenAI.
Реалізовано розділення інтерфейсів (User UI та Admin Dashboard) для демонстрації розуміння бізнес-процесів.

## Швидкий запуск (Windows)

Для максимальної зручності створено файл `run.bat`.
1. Клікніть двічі на `run.bat`.
2. Скрипт автоматично створить віртуальне середовище, встановить залежності.
3. Прямо в консолі вас попросять ввести ваш `OPENAI_API_KEY`.
4. Сервер запуститься автоматично і сам відкриє ТРИ вкладки у вашому браузері:
   - `http://127.0.0.1:8000/` — Клієнтський чат (UI в стилі ChatGPT).
   - `http://127.0.0.1:8000/admin` — Панель адміністратора (моніторинг токенів та витрат).
   - `http://127.0.0.1:8000/docs` — Документація API (Swagger).

## Архітектура
- Клієнтська частина: Приховано всі технічні метрики, залишено лише зручний UX для спілкування.
- Адмінська частина: Таблиця сесій, яка в реальному часі підтягує дані по витрачених токенах та грошах, а також містить швидкий перехід до Swagger-документації.

Для тестування API ви можете скористатися вбудованим інтерактивним інтерфейсом Swagger UI, який доступний за адресою /docs після запуску сервера.

### Розрахунок вартості (Pricing & Model)

Усі розрахунки токенів та витрат у панелі адміністратора базуються на стандартних тарифах для моделі `gpt-4o-mini`:
* **Prompt (Input) tokens:** $0.15 за 1 000 000 токенів ($0.00000015 за токен)
* **Completion (Output) tokens:** $0.60 за 1 000 000 токенів ($0.0000006 за токен)

### Відомі обмеження та рекомендації для Production

Для пришвидшення розробки та фокусу на основній бізнес-логіці деякі компоненти були реалізовані у спрощеному вигляді. Для переведення сервісу у повноцінний Production рекомендується доробити/переробити наступне:

* **Керування контекстом діалогу:** Зараз вся історія повідомлень сесії надсилається до моделі. Для довгих чатів варто додати сумаризацію старих повідомлень для оптимізації витрати токенів.
* **Авторизація та безпека:** У поточному прототипі відсутня перевірка прав доступу (API keys або JWT для користувачів), тому кожен має доступ до загальних сесій.
* **Тестування:** Поточна версія не містить автоматизованих unit- та інтеграційних тестів (pytest)
